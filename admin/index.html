Admin alphandiaye.online

Modifie ton site directement à l’écran, puis publie : la modification part sur GitHub et le site est à jour en une minute environ.

Comment créer le jeton (une seule fois)
  1. Ouvre GitHub → Fine-grained tokens → Generate new token.
  2. Nom : « Admin site », expiration : 90 jours.
  3. Repository access : Only select repositories → alphandiaye.
  4. Permissions → Repository permissions → Contents : Read and write (rien d’autre).
  5. Génère, copie le jeton et colle-le ici.

Le jeton n’est jamais écrit dans le code du site : il reste dans ce navigateur. Sans « Rester connecté », il est oublié à la fermeture de l’onglet.
